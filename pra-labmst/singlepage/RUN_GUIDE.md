# 🚀 How to Run This React Project

## Quick Start Guide

### Step 1: Open Terminal/Command Prompt
Navigate to your project folder:
```bash
cd pra-labmst/singlepage
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Start Development Server
```bash
npm run dev
```

### Step 4: Open in Browser
Go to: **http://localhost:5173**

---

## 📋 What You'll See

1. **Login Page** (default page)
   - Enter any name and password
   - Click "Sign In"
   - See success message

2. **Sign Up Page**
   - Click "Create one here" link
   - Fill the form with:
     - Name (required)
     - Email (must contain @)
     - Password (minimum 6 characters)
     - Confirm Password (must match password)
   - Click "Create Account"
   - Automatic redirect to login

1. Make sure Node.js is installed
2. Check that you're in the correct folder (`singlepage`)
3. Try `npm install` again if it fails
