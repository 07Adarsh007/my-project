## 🌐 **HOW TO TEST THE APP**

### Step 1: Open Browser
Go to: **http://localhost:5173**

### Step 2: Test Login
1. Enter any name (e.g., "John Doe")
2. Enter any password (e.g., "password123")
3. Click **"Sign In"**
4. ✅ See success message

### Step 3: Test Registration
1. Click **"Create one here"** link
2. Fill form:
   - **Name**: Your name
   - **Email**: your@email.com
   - **Password**: 6+ characters
   - **Confirm Password**: Same as password
3. Click **"Create Account"**
4. ✅ See success message + auto-redirect

### Step 4: Test Validation
- Try empty fields → Error messages
- Try wrong email → "Please enter valid email"
- Try short password → "Password must be at least 6 characters"
- Try mismatched passwords → "Passwords do not match"

## 🆘 **TROUBLESHOOTING**

### If server doesn't start:
```bash
# Clear cache and reinstall
npm cache clean --force
npm install
npm run dev
```

### If port 5173 is busy:
The server will automatically use another port (like 5174)

### If you see errors:
1. Check that Node.js is installed
2. Make sure you're in the `singlepage` folder
3. Try `npm install` again
