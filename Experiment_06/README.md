Run Experiment_06 projects

From the `Experiment_06` folder you can run the small backend server or the form-validation frontend.

- Start the backend server:

```powershell
npm run server
```

- Start the frontend (Vite dev server):

```powershell
npm run client
```

Notes
- `npm run client` changes directory into the `form validation` folder and runs its `dev` script.
- If you want to run both at the same time, open two terminals and run the two commands above in parallel.
